# Microduck wordmark

The [Pollen Robotics press kit](https://pollen-robotics.com/microduck/press-kit/) supplies `wordmark.svg`. It is the original `BRAND/microduck-wordmark.svg` from the kit, shown with its original colors and proportions. Pollen Robotics provides the branding separately from the software license.

`wordmark-badge.webp` is a small lossless raster export of the same wordmark for the README.
