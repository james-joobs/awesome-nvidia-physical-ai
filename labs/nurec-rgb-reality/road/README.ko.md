# 카메라 RGB를 노면에 재투영하기

[English](README.md) · [Reality View 실습](../README.ko.md)

**RGB 노면 재투영 + 3D 장면**에서 도로를 둘러보세요. 같은 시점에서 **3DGS 배경 + 시간별 차량**으로 전환하면 차선과 노면 질감을 비교할 수 있습니다. **RGB 노면만 보기**에서는 실제 사진이 덮는 범위를 확인할 수 있습니다.

| 단계 | 입력과 출력 |
| --- | --- |
| 도로와 하늘 구분 | Mask2Former Cityscapes로 매 RGB 이미지의 픽셀을 도로, 하늘, 그 밖의 클래스로 나눕니다. |
| 카메라 보정 | LoMa-B로 여러 이미지에 찍힌 고정 지점을 찾습니다. BA에서 카메라별 초점거리, 시간별 카메라 리그 자세, 3D 특징점 위치를 같이 조정합니다. |
| 노면 높이 추정 | DA3와 Depth Pro 2-B의 깊이가 비슷한 지점에 LoMa로 삼각측량한 점을 더해 완만한 도로 표면을 맞춥니다. |
| 텍스처 만들기 | 노면의 3D 점을 각 카메라로 투영합니다. 두 시점 이상에서 도로로 확인된 곳에 가장 촘촘하게 찍힌 RGB를 기록합니다. 깊이가 크게 어긋나는 픽셀은 제외합니다. |
| 3D 장면과 합성 | 도로 표면에 RGB를 입힙니다. 텍스처가 있는 위치의 노면 Gaussian은 약하게 표시하고 주변 건물과 시간별 차량은 기존 레이어에서 가져옵니다. 반복해서 하늘로 투영되는 높은 Gaussian은 제거합니다. |

이 예제는 저장한 17개 시점을 오프라인에서 보정합니다. 짧은 구간에서 불안정해지기 쉬운 주점과 카메라 간 상대 위치는 고정했습니다. Depth Pro 2는 8프레임씩 겹쳐 읽고, 깊이를 카메라별로 DA3 장면의 상대 단위에 맞췄습니다. 그 위에 기존 DA3 차량 레이어를 사용합니다.

## 같은 PandaSet 도로에서 확인한 결과

- RTX 5090에서 Mask2Former, LoMa, Depth Pro 2를 각각 RGB 102장에 실행했습니다. LoMa가 이미지 쌍 441개를 확인해 기하 필터를 통과한 매칭 221,588개를 얻었습니다. BA에는 특징점 트랙 3,200개를 사용하고 500개를 검증용으로 분리했습니다.
- 검증 트랙마다 두 시점으로 3D 점을 구하고 나머지에 재투영했습니다. 1,887개 검증 지점에서 90백분위 오차가 **6.72px → 6.39px**로 줄었습니다. 중앙값은 양쪽 모두 약 1.73px입니다. 기준 이미지 크기는 756 × 420입니다.
- 텍스처를 만들 때 제외한 전방 이미지 5장에서 공통으로 보이는 디테일 픽셀 32,783개를 비교했습니다. 보정과 깊이 보완을 함께 적용한 경우 8비트 밝기 디테일 평균 오차가 **6.71 → 6.63**으로 줄었습니다. 이 5장은 카메라 보정과 표면 추정에 사용했습니다.
- 텍스처는 **1600 × 723**입니다. 초기 실험에서는 기존 배경 Gaussian 1,173,892개 중 하늘로 분류된 76,712개를 제거했습니다. 먼 구간이나 크게 돌아본 시점에서는 텍스처 경계와 주변 물체의 잔상이 남습니다.

## 하늘과 건물 벽면 보정

기본 화면에서는 고정 노면에 건물 텍스처와 별도 하늘 배경을 합성합니다. LoMa로 추적한 건물 특징점과 DA3 깊이를 사용해 수직 외벽을 맞추고, 세 시점 이상에서 건물로 확인된 부분에 원본 RGB를 입혔습니다. 하늘은 Mask2Former가 고른 픽셀을 카메라 방향에 따라 이어 붙입니다. 충분히 관측된 영역은 상반구의 약 13%입니다. 시야가 닿지 않은 방향은 주변 하늘색을 이어 채웠습니다.

두 번째 오프라인 BA에서는 전방 카메라를 기준으로 나머지 카메라의 상대 자세도 조정하고, 시간에 따른 보정값의 급격한 변화를 줄였습니다. 같은 LoMa 매칭과 검증 지점 1,887개로 비교했습니다.

| 카메라 보정 | 전체 중앙값 | 전체 90백분위 | 벽면 90백분위 |
| --- | ---: | ---: | ---: |
| 처음 RGB로 추정한 카메라 | 1.73px | 6.72px | 6.25px |
| 1차 LoMa + 리그를 고정한 BA | 1.73px | 6.39px | 5.52px |
| 2차 LoMa + 리그 상대 자세 보정 BA | 1.61px | 5.97px | 5.94px |

2차 BA는 계산 한도인 220회에 도달했습니다. 새 자세는 하늘 투영과 하늘 잔상 필터에 적용했습니다. 벽면은 오차가 더 낮았던 1차 보정값으로 RGB를 투영했습니다. 노면 역시 텍스처 생성에서 제외한 다섯 시점의 공통 픽셀 36,355개에서 기존 결과의 밝기 디테일 오차가 더 낮았습니다(6.70 대 6.79). 그래서 기존 노면 표면과 텍스처를 유지했습니다. 일부 건물 경계와 먼 곳에는 여전히 이음새나 잔상이 보입니다.

[설치·실행 명령](README.md#reproduce)에 따라 RGB 입력에서 노면 텍스처까지 다시 만들 수 있습니다. 이미 만들어 둔 브라우저용 파일은 아래 명령으로 GPU 없이 확인할 수 있습니다.

```bash
python3 labs/nurec-rgb-reality/road/check.py
```
