## Architecture and workflow

The following is an illustrative workflow, not an official architecture or a claim of automatic integration.

**Camera observations and calibration → visual SLAM → pose and odometry → navigation or mapping**

## Example use case

Estimate a moving robot’s pose from cameras for a navigation workflow.
