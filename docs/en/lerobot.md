# LeRobot

## Architecture and workflow

The following is an illustrative workflow, not an official architecture or a claim of automatic integration.

**Robot demonstrations → dataset and preprocessing → policy training → evaluation and robot control**

## Example use case

Collect and use demonstration data to train a robot manipulation policy.
