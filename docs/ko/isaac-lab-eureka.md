## 소개

언어 모델을 이용한 보상 함수 생성 연구 코드.

## 개념적 워크플로

```mermaid
flowchart LR
    n0["작업 설명"] --> n1
    n1["언어 모델로 보상 함수 제안"] --> n2
    n2["학습·평가"] --> n3
    n3["보상 개선"]
```

## 활용 흐름과 사례

작업 설명 → 언어 모델로 보상 함수 제안 → 학습·평가 → 보상 개선. 개념적인 흐름이며 버전별 사전 요구사항과 지원 구성은 공식 문서를 확인한다.

**활용 사례:** 보행 보상 함수 반복 개선. 지원 입력과 모델 버전은 공식 출처에서 확인한다.

**연결 기술:** Isaac Lab.

## 구성과 실제 활용

연구 워크플로는 언어 모델로 시뮬레이션 로봇 작업의 보상 함수를 제안하고 로봇 학습을 통해 후보를 평가합니다. 연구 예시로 작업 성능에 따라 생성된 보상 후보를 비교할 수 있습니다. 생성된 보상과 코드를 검토해야 하며 공개 저장소의 라이선스는 미확인입니다.
