# MoGe

[← 전체 목록](../../README.ko.md) · [English](../en/moge.md)

MoGe는 RGB 이미지 한 장에서 밀집 기하를 예측합니다. 버전별 출력 규약이 다르므로 저장소의 체크포인트 예제로 시작합니다.

![MoGe 기법 개요](https://raw.githubusercontent.com/microsoft/MoGe/main/assets/overview_simplified.png)

*RGB 입력이 기하 예측으로 바뀌는 과정을 보여줍니다. 사용하는 체크포인트의 출력 규약을 확인하세요.* [공식 그림 출처](https://github.com/microsoft/MoGe)

## 어떻게 동작하나

영상 인코더가 특징을 추출하고 기하 출력 헤드가 포인트맵과 유효 영역 정보를 예측합니다. 초기 방법은 전역 스케일과 이동의 불확실성을 고려합니다. 이후 지원 체크포인트에서는 미터 단위 기하 등으로 출력이 확장됩니다. 포인트맵은 유효 이미지 픽셀마다 3D 점을 지정합니다.

## 실전 워크플로

작업대 영상에서 모델을 실행하고 측면 시점에서 포인트맵을 시각화합니다. 무효 픽셀을 제외하고 추정 거리를 알려진 기준과 비교합니다. 결과를 장면 재구성의 초기 기하로 사용할 수 있습니다.

## 검증할 항목

체크포인트별 좌표계, 미터 스케일과 유효 마스크를 확인합니다. 먼 영역과 깊이가 급변하는 경계를 점검합니다. 충돌 판단에 쓰기 전 보정된 스테레오나 실측 형상과 비교합니다.

## 공개 범위와 라이선스

각 모델 버전의 코드·체크포인트와 의존성 라이선스를 별도로 확인하세요.
