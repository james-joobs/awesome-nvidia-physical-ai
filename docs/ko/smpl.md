# SMPL

[← 전체 목록](../../README.ko.md) · [English](../en/smpl.md)

SMPL은 학습된 파라미터 인체 메시입니다. 추정한 인체 파라미터 시퀀스는 동작을 나타내며 리타기팅의 중간 표현으로 사용할 수 있습니다.

## 어떻게 동작하나

체형 계수는 템플릿과 관절 위치를 바꿉니다. 자세 파라미터는 관절을 움직이고 자세 보정 변형을 제어합니다. 선형 블렌드 스키닝으로 뼈대와 함께 정점을 변형합니다. 관측에서 파라미터를 구하는 작업은 별도 추정 시스템이 수행합니다.

```mermaid
flowchart LR
    B["체형 계수"] --> T["변형 템플릿과 관절"]
    P["관절 자세"] --> C["자세 보정"]
    T --> S["선형 블렌드 스키닝"]
    C --> S
    S --> M["자세가 적용된 메시"]
```

## 실전 워크플로

이용 조건이 맞는 모션 데이터셋의 파라미터로 인체 메시와 관절 궤적을 복원합니다. 알려진 동작과 뼈대를 대조한 뒤 필요한 관절과 접촉 정보를 대상 로봇 형상에 맞춰 매핑합니다.

## 검증할 항목

모델 버전, 단위, 루트 방향과 관절 정의를 확인합니다. 리타기팅 후 발 접촉과 움직임 연속성을 평가합니다. 전체 모델과 SMPL-Body 부분 집합의 이용 조건은 각각 확인합니다.

## 공개 범위와 라이선스

모델 데이터, 코드, 파생물 및 연구·상업적 사용의 조건이 다를 수 있으므로 정확한 모델 라이선스와 접근 조건을 확인하세요.
