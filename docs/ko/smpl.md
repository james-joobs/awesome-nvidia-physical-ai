# SMPL

[← 전체 목록](../../README.ko.md) · [English](../en/smpl.md) · [공식 소스](https://smpl.is.tue.mpg.de/) · [공식 문서 / 관련 프로젝트](https://smpl.is.tue.mpg.de/license.html)

사람의 체형과 자세를 3D로 표현하는 파라미터 모델 계열입니다.

**공개 및 이용 조건:** 모델 데이터, 코드, 파생물 및 연구·상업적 사용의 조건이 다를 수 있으므로 정확한 모델 라이선스와 접근 조건을 확인하세요.

## 구성과 활용 흐름

```mermaid
flowchart LR
    A["체형 + 자세 파라미터"] --> B["인체 모델"] --> C["3D 메시"] --> D["후속 분석"]
```

*이 안내서의 개념도이며, 지원 구현은 공식 자료를 확인하세요.*

해당 모델의 접근 및 이용 조건을 확인한 뒤 체형·자세 파라미터를 입력하거나 추정해 인체 메시를 생성하고 검토합니다.

## 활용 사례

인체 동작 분석, 애니메이션, 복원 연구에 활용할 수 있습니다.

## 연계 기술

모션 캡처와 리타기팅 흐름에 연결할 수 있으며 좌표계와 로봇 신체 매핑을 별도로 처리해야 합니다.
