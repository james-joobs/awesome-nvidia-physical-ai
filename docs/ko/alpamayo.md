# Alpamayo

[← 전체 목록](../../README.ko.md) · [English](../en/alpamayo.md)

## 소개

자율주행 추론·행동 모델 계열.

## 개념적 워크플로

```mermaid
flowchart LR
    n0["주행 상황 제공"] --> n1
    n1["추론·행동 모델 실행"] --> n2
    n2["시나리오에서 행동 평가"]
```

## 활용 흐름과 사례

주행 상황 제공 → 추론·행동 모델 실행 → 시나리오에서 행동 평가. 개념적인 흐름이며 버전별 사전 요구사항과 지원 구성은 공식 문서를 확인한다.

**활용 사례:** 시뮬레이션에서 주행 판단 평가. 지원 입력과 모델 버전은 공식 출처에서 확인한다.

**연결 기술:** AlpaSim, AlpaGym.

## 구성과 구체적인 활용

Alpamayo는 주행 추론과 행동 모델 계열이다. AlpaSim은 폐루프 시뮬레이션 환경을 제공하고 AlpaGym은 시뮬레이션 결과를 강화학습에 연결한다.

가상 주행 시나리오에서 후보 궤적을 평가하고 지정된 지표로 모델 동작을 비교한다.

[공식 기술 자료](https://github.com/NVlabs/alpamayo-recipes)

## 공개 및 이용 조건

공개 가중치의 조건과 접근 절차는 모델 버전별 상이. 사용 전 해당 버전과 모델·데이터·바이너리·의존성의 조건을 각각 확인한다.
