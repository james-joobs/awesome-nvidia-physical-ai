# Isaac ROS Manipulation
[← 목록으로](../../README.ko.md) · [English](../en/isaac-ros-manipulation.md)

ROS 2 기반 로봇팔 조작 워크플로.

**공식 자료:** [저장소](https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_manipulation)  
**라이선스와 범위:** 코드 Apache-2.0; 모델·의존성 별도.

> 공식 이미지: 확인된 이미지를 찾지 못해 아래 개념 흐름을 제공합니다.

## 구성과 워크플로

아래는 활용 흐름을 이해하기 위한 개념도입니다. 공식 아키텍처나 자동 연결을 뜻하지 않습니다.

**로봇·장면 설정 → 인식 → 파지 또는 동작계획 → 로봇팔 실행**

## 활용 사례

로봇팔 조작에 필요한 ROS 2 파이프라인을 구성합니다.

## 연결 기술

Isaac ROS, cuRobo, ROS 2.

버전과 사용 환경에 따라 호환성, 데이터 형식, 모델 및 의존성 조건을 공식 자료에서 확인하세요.
