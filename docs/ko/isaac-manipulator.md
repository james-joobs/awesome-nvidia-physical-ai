# Isaac Manipulator

[← 전체 목록](../../README.ko.md) · [English](../en/isaac-manipulator.md)

## 소개

로봇팔 인식·파지·계획용 참조 워크플로.

## 개념적 워크플로

```mermaid
flowchart LR
    n0["센서 데이터 수집"] --> n1
    n1["물체 자세 추정"] --> n2
    n2["파지와 동작 계획"] --> n3
    n3["로봇 실행"]
```

## 활용 흐름과 사례

센서 데이터 수집 → 물체 자세 추정 → 파지와 동작 계획 → 로봇 실행. 개념적인 흐름이며 버전별 사전 요구사항과 지원 구성은 공식 문서를 확인한다.

**활용 사례:** 로봇 팔로 물체 집기. 지원 입력과 모델 버전은 공식 출처에서 확인한다.

**연결 기술:** Isaac ROS, FoundationPose, cuRobo.

## 구성과 실제 활용

일반적인 조작 그래프는 카메라 인식, 물체 자세 추정, 파지 또는 동작 계획, 로봇 제어를 조합합니다. 예를 들어 로봇팔은 물체의 추정 자세를 사용해 집기 동작을 계획합니다. 지원 로봇·센서·구성 요소는 선택한 참조 워크플로와 버전에 따라 달라집니다.

[공식 문서](https://nvidia-isaac-ros.github.io/)

## 공개 및 이용 조건

Isaac ROS 패키지·모델 및 구성 요소마다 조건 상이. 사용 전 해당 버전과 모델·데이터·바이너리·의존성의 조건을 각각 확인한다.
