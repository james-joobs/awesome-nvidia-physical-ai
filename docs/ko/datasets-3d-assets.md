# 3D 에셋과 환경

[전체 목록](../../README.ko.md) · [English](../en/datasets-3d-assets.md)

공식 데이터셋 카드를 기준으로 형식, 접근 조건과 라이선스를 각각 확인한다. 공개 접근과 제한 없는 이용 권한은 다르다.

## 선택 및 활용 흐름

이 그림은 개념적 사용 흐름이다.

```mermaid
flowchart LR
  S0["에셋 검색"]
  S1["형식과 라이선스 확인"]
  S2["시뮬레이션 장면에 추가"]
  S3["검증"]
  S0 --> S1 --> S2 --> S3
```
