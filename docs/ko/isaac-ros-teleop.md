## 구성과 워크플로

아래는 활용 흐름을 이해하기 위한 개념도입니다. 공식 아키텍처나 자동 연결을 뜻하지 않습니다.

**XR 조작자 입력 → ROS 2 원격 조작 인터페이스 → 로봇 명령 → 로봇 응답**

## 활용 사례

XR 장치를 사용해 지원되는 로봇을 원격 조작합니다.

## 연결 기술

Isaac ROS, XR devices, robot drivers.

버전과 사용 환경에 따라 호환성, 데이터 형식, 모델 및 의존성 조건을 공식 자료에서 확인하세요.
