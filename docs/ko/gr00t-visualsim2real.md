# GR00T-VisualSim2Real
[← 목록으로](../../README.ko.md) · [English](../en/gr00t-visualsim2real.md)

휴머노이드 시각 기반 이동·조작의 시뮬레이션-현실 전이.

**공식 자료:** [저장소](https://github.com/NVlabs/GR00T-VisualSim2Real)  
**라이선스와 범위:** Apache-2.0; 모델·로봇 자산 별도.

> 공식 이미지: 확인된 이미지를 찾지 못해 아래 개념 흐름을 제공합니다.

## 구성과 워크플로

아래는 활용 흐름을 이해하기 위한 개념도입니다. 공식 아키텍처나 자동 연결을 뜻하지 않습니다.

**시뮬레이션 시각 관측 → 이동·조작 정책 학습 → 평가 → 실제 로봇 전이**

## 활용 사례

휴머노이드의 시각 기반 이동·조작을 시뮬레이션에서 실제 하드웨어로 전이하는 연구에 사용합니다.

## 연결 기술

Isaac Lab, humanoid robots, sim-to-real.

버전과 사용 환경에 따라 호환성, 데이터 형식, 모델 및 의존성 조건을 공식 자료에서 확인하세요.
