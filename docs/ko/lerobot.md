# LeRobot
[← 목록으로](../../README.ko.md) · [English](../en/lerobot.md)

로봇 데이터셋과 모델 학습 도구; Capture와 연동 가능.

**공식 자료:** [저장소](https://github.com/huggingface/lerobot)  
**라이선스와 범위:** Apache-2.0; Hugging Face 프로젝트.

![LeRobot robot control demonstration](https://raw.githubusercontent.com/huggingface/lerobot/main/media/readme/robots_control_video.webp)
*이미지 출처: [Repository](https://github.com/huggingface/lerobot)*

## 구성과 워크플로

아래는 활용 흐름을 이해하기 위한 개념도입니다. 공식 아키텍처나 자동 연결을 뜻하지 않습니다.

**로봇 시연 → 데이터셋·전처리 → 정책 학습 → 평가·로봇 제어**

## 활용 사례

시연 데이터를 수집해 로봇 조작 정책을 학습합니다.

## 연결 기술

Hugging Face, Isaac Capture, Isaac GR00T.

버전과 사용 환경에 따라 호환성, 데이터 형식, 모델 및 의존성 조건을 공식 자료에서 확인하세요.
