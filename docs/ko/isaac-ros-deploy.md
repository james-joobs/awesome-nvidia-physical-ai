# Isaac ROS Deploy
[← 목록으로](../../README.ko.md) · [English](../en/isaac-ros-deploy.md)

학습된 로봇 정책을 시뮬레이션 및 실제 하드웨어에 배포.

**공식 자료:** [저장소](https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_deploy)  
**라이선스와 범위:** Apache-2.0; 런타임·모델 별도.

> 공식 이미지: 확인된 이미지를 찾지 못해 아래 개념 흐름을 제공합니다.

## 구성과 워크플로

아래는 활용 흐름을 이해하기 위한 개념도입니다. 공식 아키텍처나 자동 연결을 뜻하지 않습니다.

**학습된 정책 → 추론 설정 → ROS 2 실행 → 시뮬레이션 또는 실제 로봇**

## 활용 사례

학습된 정책을 지원되는 시뮬레이션 또는 로봇 환경에 배포합니다.

## 연결 기술

Isaac Lab, Isaac ROS, ROS 2.

버전과 사용 환경에 따라 호환성, 데이터 형식, 모델 및 의존성 조건을 공식 자료에서 확인하세요.
