# DexMimicGen

[← 목록으로](../../README.ko.md) · [English](../en/dexmimicgen.md)

DexMimicGen은 시연 생성 방법을 양손 정교 조작에 확장합니다. 두 팔이 함께 움직일 때는 말단 장치 사이의 관계를 유지하고, 한 팔이 작업을 마쳐야 다른 팔이 시작할 수 있으면 하위 작업의 순서를 맞춥니다.

## 아키텍처와 데이터 흐름

| 구성 요소 | 입력·처리·출력 |
|---|---|
| **병렬 하위 작업** | 두 팔이 각각 독립적으로 목표를 달성할 수 있으면 두 팔의 구간을 따로 선택해 변환합니다. |
| **협응 하위 작업** | 두 팔이 물체를 함께 조작하거나 한쪽에서 다른 쪽으로 넘길 때는 기준 물체 자세에 따라 관련 구간을 함께 변환해 동작 사이의 협응을 유지합니다. |
| **순차 하위 작업과 평가** | 의존 관계가 어떤 하위 작업을 먼저 마쳐야 하는지 정합니다. 환경에서 양팔 행동을 실행하고 관측과 성공 여부를 기록합니다. |

공식 구성도는 독립 동작, 협응 동작, 순서가 있는 동작을 구분합니다. 두 팔의 시연을 새로운 배치에서 어떻게 재사용할지 결정하는 기준입니다. [공식 그림 출처](https://dexmimicgen.github.io/)

## 적용 예시

1. 양손 물체 전달에서는 첫 팔의 파지, 양팔이 협응하는 전달, 두 번째 팔의 배치 구간을 표시합니다. 두 팔이 함께 움직이거나 이전 작업의 종료를 기다리는 지점을 지정합니다.
2. 물체나 고정구 자세를 무작위화합니다. 모방학습용 에피소드를 고르기 전에 시뮬레이션에서 전달 타이밍, 말단 장치 간 간격, 최종 작업 결과를 확인합니다.

## 검증할 항목

- 두 팔의 궤적과 손가락 명령을 모두 살펴봅니다. 작업을 완료했어도 전달 타이밍이 일관되지 않거나 접촉이 부자연스러울 수 있습니다.
- 로봇, 시뮬레이터, 데이터셋의 이용 조건을 각각 확인합니다. 한 로봇 형태에서의 결과는 다른 로봇에서 같은 하위 작업 구성이 검증되었다는 뜻이 아닙니다.
