[← 전체 목록](../../README.ko.md) · [English](../en/groot-mimic-dreams.md)

## 소개

로봇 시연·합성 데이터 생성 기술·워크플로.

## 개념적 워크플로

```mermaid
flowchart LR
    n0["시연 수집"] --> n1
    n1["변형 데이터 또는 합성 관측 생성"] --> n2
    n2["생성 데이터 검토"] --> n3
    n3["정책 개발에 활용"]
```

## 활용 흐름과 사례

시연 수집 → 변형 데이터 또는 합성 관측 생성 → 생성 데이터 검토 → 정책 개발에 활용. 개념적인 흐름이며 버전별 사전 요구사항과 지원 구성은 공식 문서를 확인한다.

**활용 사례:** 로봇 학습 데이터 확장. 지원 입력과 모델 버전은 공식 출처에서 확인한다.

**연결 기술:** Isaac GR00T, Isaac Sim.

## 구성과 실제 활용

이 이름들은 하나로 자동 연결되는 제품이 아니라 데이터 생성 접근법을 가리킵니다. GR00T-Mimic은 시연 확장, GR00T-Dreams는 합성 데이터 생성과 관련됩니다. GR00T FAQ에 따르면 Cosmos 합성 학습 데이터의 제품용 파이프라인은 아직 개발 중이므로 선택한 버전의 제공 범위를 확인하세요.

[공식 문서](https://github.com/NVIDIA/Isaac-GR00T/blob/main/FAQ.md)
